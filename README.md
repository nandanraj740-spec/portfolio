# Nandanraj | Portfolio & ATS Resume Website

Modern, responsive personal portfolio and ATS-compliant CV website for **Nandanraj** (MCA Scholar & Full-Stack / Mobile Developer).

🌐 **Live URL**: [https://nandanraj740-spec.github.io/portfolio/](https://nandanraj740-spec.github.io/portfolio/)

---

## 🌟 Key Features

- **Dual-Mode Experience**:
  - **Interactive Modern Bento Portfolio**: Aesthetic, bento-grid header, project showcase with badges and live links, research papers, education timeline, skill chips, and spoken language indicators.
  - **ATS Resume View**: 1-click toggle to a single-column, standard-typography format strictly adhering to AI and ATS screening rules (as specified in recruitment guidelines).
- **Print / PDF Ready**: Uses dedicated `@media print` rules to automatically export a clean, high-contrast ATS-compliant resume upon pressing `Ctrl+P` or clicking **Print / Save CV**.
- **Light & Dark Theme**: Sleek indigo/emerald color palette with persistent theme storage in `localStorage`.
- **Interactive Quick-Copy Pills**: 1-click clipboard copy for email addresses and contact information with animated toast alerts.
- **Fast & Zero-Dependency**: Pure vanilla HTML5, modern CSS3, and JavaScript—loads instantly on mobile and desktop without framework bloat.
